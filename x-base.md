
| Project | Sub-Category | Purpose & Focus | Core Tools Included | Why it fits your philosophy |
| :--- | :--- | :--- | :--- | :--- |
| **`sbase`** | **File Operations** | Portable filesystem manipulation matching old `fileutils`. | `cp`, `mv`, `rm`, `ls`, `mkdir`, `rmdir`, `chmod`, `chown`, `ln`, `touch`, `du`, `tar`, `find` | Pure POSIX C implementations wrapper around standard file system calls. No heavy GNU options or layout extensions. |
| **`sbase`** | **Text Processing** | Clean data parsing and transformation matching old `textutils`. | `cat`, `sort`, `uniq`, `cut`, `paste`, `head`, `tail`, `join`, `split`, `wc`, `tr`, `grep`, `sed`, `awk`, `cols` | Operates completely in memory streams (`stdin` to `stdout`). Stripped of bloated locale/charset translations. |
| **`sbase`** | **System & Scripting Primitives** | Environment control utilities matching old `sh-utils`. | `echo`, `env`, `uname`, `id`, `basename`, `dirname`, `date`, `sleep`, `true`, `false`, `yes`, `expr`, `tee`, `kill`, `xargs` | Single-purpose logical blocks. No external auditing hooks or intricate telemetry structures tracking your execution. |
| **`ubase`** | **Hardware & Partitioning** | Interacting with physical disks, blocks, and low-level Linux layout. | `fdisk`, `mkswap`, `losetup`, `mknod`, `pagesize`, `blkdiscard` | Raw interfaces to Linux kernel block layers. They do not query desktop environment abstraction layers. |
| **`ubase`** | **Kernel & Memory State** | Inspecting or altering active Linux kernel runtime variables. | `dmesg`, `lsmod`, `insmod`, `rmmod`, `swapon`, `swapoff`, `sysctl`, `freem` | Direct wrappers around raw Linux system calls (`syslog`, `delete_module`, `swapon`). They execute and immediately drop out of memory. |
| **`ubase`** | **Process & Session Controls** | Linux-specific terminal management, process priorites, and early init routines. | `chroot`, `pivot_root`, `halt`, `reboot`, `watchdog`, `renice`, `su`, `ctrlaltdel` | Stripped down to direct execution. `su` handles passwords natively without invoking a 10-layer PAM/audit architecture. |
